# LP Casse Automatiche — Developer Documentation

## Obiettivo

Realizzare una landing/sito commerciale per SPLIT/GL dedicato alle casse automatiche rendiresto VNE e ai sistemi cassa completi di Custom S.p.A.

Il sito deve posizionarsi come soluzione locale e verticale per attività commerciali, Ho.Re.Ca., retail, farmacie, tabacchi, supermercati, panifici, macellerie, ristorazione e punti vendita con gestione contante.

## Proposta commerciale

Vendiamo/noleggiamo casse automatiche VNE abbinate a un Sistema Cassa Completo Touch di Custom S.p.A.:

- Cassa automatica rendiresto VNE
- Sistema cassa touch SILK II Android o Fusion-N 2.0 RT
- Misuratore fiscale / stampante fiscale
- Software gestionale KeepUp Smart
- Installazione, configurazione e assistenza
- Formula noleggio operativo all-inclusive
