# Tech Stack

## Framework

Next.js con App Router.

## Linguaggio

TypeScript obbligatorio.

## Styling

TailwindCSS con componenti riutilizzabili.

## Rendering

- Homepage: SSG/ISR se contenuti statici
- Pagine prodotto: SSG
- Form contatti: Server Actions o API route
- Landing campagne ADS: pagine statiche ottimizzate

## Deploy

Vercel.

## Performance target

- Lighthouse Performance: >90
- SEO: >95
- Accessibility: >90
- Best Practices: >95

## Librerie consigliate

- `next`
- `react`
- `typescript`
- `tailwindcss`
- `lucide-react`
- `zod`
- `react-hook-form`
- `@hookform/resolvers`
- `next-sitemap`
- `schema-dts`

## Convenzioni

- Componenti UI in `/components`
- Dati prodotti in `/data`
- Configurazioni SEO in `/lib/seo`
- Utility in `/lib`
- Tipi globali in `/types`
